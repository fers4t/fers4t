# Ferşat Özçelik

### Senior Software Engineer

I am a philosophy graduate and software engineer based in Rize, Türkiye. I design and ship product systems across the web, backend services, developer tooling, and native macOS utilities.

My work is grounded in pragmatic engineering: clear system boundaries, deliberate technology choices, and software that remains understandable after the first release.

## Engineering principles

- Keep architecture proportional to the problem.
- Prefer explicit contracts and predictable failure modes.
- Automate repetitive work, but keep the result observable and reversible.
- Treat maintainability and operational clarity as product requirements.
- Optimize for long-term ownership rather than short-term novelty.
